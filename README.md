# Personal Portfolio

This is a modern, responsive personal portfolio built with Vite, React, TypeScript, and Tailwind CSS.

## Deployment

This app is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the `main` branch.

## Local Development
If you want to run this locally:
1. Ensure Node.js is installed.
2. Run `npm install` within the project root.
3. Run `npm run dev` to start the development server.
